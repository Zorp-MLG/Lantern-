# Lantern-
An "lantern" using leds, an microcontroller and a microphone that sends voice levels to an microcontroller that you can use while trick and treating or playing an horror game to control your rooms light 


# How to set up the microcontroller 

1. make your simple LED code in c++ or other supported languages

2. flash your microcontroller from the official website
   by plugging in your USB or other types to your device( computer, for example)
   and then follow the official sites instructions

   if you use esp32 go to this website: https://www.espressif.com/en/support/download/all
   if you want the official guide go to: https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s3/download-guidelines.html 


4. Put the code on the microcontroller
   

5. disconnect it from the USB

6. solder it on the PCB

7. Maybe charge the battery thru the microcontroller first if your battery doesn't have charge

8. then your done!
